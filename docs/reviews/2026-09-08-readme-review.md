# 首页 README 审核记录

范围：根目录 `README.md`、`README.en.md`；在 pi-auto-worktree 技能提交 `6d9c5b6` 之后单独审核。

## 发现与修复

| 问题 | 影响 | 修复 |
|:---|:---|:---|
| 中文首页 CC 条目使用 `•`，其他条目使用 Markdown `-` | CC 条目解析为普通段落，而非列表项，缩进与间距不一致 | 全部使用标准 Markdown 列表，平台专用技能独立分组 |
| clone、mkdir、for、ln 堆在一条长命令中 | 窄屏难读，复制后会批量安装不兼容当前平台的技能 | 克隆只执行一次，各平台使用短命令按需安装，不再强制覆盖已有路径 |
| “CC + Codex 通用”无条件表述 | CC hooks 和 pi 启动器不能跨平台执行，容易误装 | 首页说明改为多平台收录，并标注各技能兼容范围 |
| 英文页缺少 marketplace 安装、CC worktree 和 Notion 待办条目 | 中英文用户得到不同的安装路径和技能列表 | 同步两种语言的安装方式、分类与 12 个仓库内技能链接 |
| 首页缺少 pi 专用安装入口 | 只软链 SKILL.md 不会安装启动器和扩展 | 新增 pi 安装段落，链接完整依赖、恢复和命名说明 |
| 中文标点、英文与数字间距不一致 | 阅读节奏不统一 | 统一中文标点、间距与列表结尾；保留已有居中页头与品牌样式 |

## 验证

- 用 `marked` 的 GFM 模式解析两份首页及 pi 技能 README/SKILL，共 4 份文档。
- 每份文档仅一个一级标题；CC / pi 条目实际生成 `<li>`，不再是普通段落。
- 所有显式相对 Markdown 链接的本地目标存在。
- 中英文首页包含相同的 12 个仓库内技能链接。
- 首页代码块没有批量安装循环，每行不超过 100 字符。
- `git diff --check` 通过。

本次验证为 Markdown 结构、生成 HTML 和本地链接检查，没有进行浏览器截图或 GitHub 页面视觉验收。
