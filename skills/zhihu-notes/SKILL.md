# 知乎文章生成器

将任意技术主题转化为**知乎风格的优质长文**，格式和文风高度契合知乎读者的阅读偏好。

---

## 内容结构

每篇文章遵循以下标准结构：

```
# 标题（吸睛，一句话说明核心价值）

> 一句话导读（引发好奇或共鸣）

## 背景 / 为什么要了解这个

（300-500字，引出问题或动机）

## 核心内容（分点展开，3-6个小节）

### 小节标题
（每个小节包含：原理 + 实战 + 注意事项）

## 实战演示 / 代码示例

（精选代码块，展示真实用法）

## 常见坑与解决方案

（知乎读者最爱的实战经验贴环节）

## 总结

（3-5条核心 takeway）

---

**相关阅读推荐**（可选，关联阅读引导）
```

## 文风规范

### 要像知乎文章一样写作

- **开头**：用一个具体场景、痛点或反常识事实切入，引发共鸣
- **语气**：第一人称经验分享，平等交流，不居高临下
- **节奏**：段落短小，多用小标题，每段不超过 3-4 句
- **配图标注**：`[配图：xxx]` 占位，方便后续手动插入
- **代码块**：技术文章必须包含真实可运行的代码示例
- **数据支撑**：适当引用具体数字，不说"很多""很久"
- **结尾**：引导评论互动，如"你们是怎么做的？""评论区见"

### 知乎读者特征

- 喜欢**深入原理**，不只是工具罗列
- 喜欢**真实踩坑经验**，不是泛泛而谈
- 喜欢**有观点有态度**，不是两边都对的废话
- 喜欢**图文并茂**，代码+输出结果+截图配合

## 主题扩展

收到主题后，**主动扩展内容**：
- 背景与适用场景
- 核心概念拆解（配对比图或表格）
- 3-5 个实操步骤
- 常见错误与正确做法对比
- 进阶用法或最佳实践
- 与同类方案的对比

---

## 处理流程

### Step 1：解析主题

提取用户提供的核心主题，判断：
- 技术深度（入门 / 进阶 / 高级）
- 文章类型（教程 / 经验 / 测评 / 对比 / 原理）
- 目标读者（新手 / 有经验者 / 专家）

### Step 2：内容规划

根据主题，规划文章结构，填充上述文章结构模板。

### Step 3：生成文案

输出完整 Markdown 格式的知乎文章，包含：
- 标题（含关键词）
- 引导语
- 完整正文（小节、段落、代码块）
- 总结
- 结尾互动引导

### Step 4：（可选）配合 XHS 卡片

如用户同时要求生成小红书配图：
- 从文章中提取 **3-5 个核心要点**
- 每张卡片对应 1 个要点
- 交给 xhs-image-gen skill 制作配图
