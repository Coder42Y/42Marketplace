# ✍️ zhihu-notes

> 一句话把任意主题转成可发布的知乎体长文。

把"想写的点子"丢进来，输出一篇结构完整、文风契合知乎读者的 Markdown 长文 —— 标准开头、核心分节、实战代码、踩坑总结、互动收尾，直接可发。

---

## Why

知乎读者喜欢"真实经验 + 深入原理 + 有态度"的内容，而不是"工具罗列 + 双方都对"的废话。这个 skill 把文风规范和文章结构内化为 prompt，让 AI 一次写出符合知乎调性的长文，省去反复重写的功夫。

## Features

- **标准结构**：标题 → 引导语 → 背景 → 核心内容（3-6 节）→ 实战代码 → 踩坑总结 → 总结互动，七段式不跑偏。
- **知乎文风**：第一人称经验分享、短段落多小标题、`[配图：xxx]` 占位、可运行代码块、具体数字支撑。
- **主题自适应**：自动判断技术深度（入门/进阶/高级）和文章类型（教程/经验/测评/对比/原理）。
- **可选联动**：可与 `xhs-image-gen` 配合，从文章要点自动生成小红书配图卡片。
- **纯 Prompt 实现**：零依赖、零安装，下载即可用。

## Quickstart

### 安装

把 skill 软链到 Claude Code / Codex 的 skills 目录：

```bash
# Claude Code
ln -s ~/42Marketplace/skills/zhihu-notes ~/.claude/skills/zhihu-notes

# Codex
ln -s ~/42Marketplace/skills/zhihu-notes ~/.codex/skills/zhihu-notes
```

### 触发

任意一句自然语言即可触发：

```
生成一篇知乎文章，主题是 Claude Code 的 skill 系统
用知乎风格写一下我是怎么搭刷题工作流的
以知乎体发一篇关于 Tmux 终端复用的文章
```

## Usage

### 常见用法

| 场景 | 触发示例 |
|------|---------|
| 技术教程 | "写一篇知乎：Python 异步编程从入门到放弃" |

### 示例输出片段

完整示例见 [`tmux-article.md`](./tmux-article.md)。典型开头长这样：

```markdown
# 【一眼就懂】Tmux 为什么是终端玩家的必备神器

> 如果你还在一个个开终端窗口，这篇文章帮你彻底搞懂什么叫"终端会话管理"。

## 背景

程序员日常是这样的：写代码的窗口、跑服务的窗口、看日志的窗口、SSH 连接的服务器——
开着四五个终端，切换来切换去，关机重开还得一个个重建。

这就是 **Tmux** 要解决的问题。
...
```
