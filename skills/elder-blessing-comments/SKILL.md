# Elder Blessing Comments

## Overview
Generate playful Chinese "长辈风" social media blessing comments: warm, sincere, slightly 土味, emoji-heavy, and ready to copy-paste into 抖音、朋友圈、微信群、小红书 or comment sections.

The goal is not polished advertising copy. The charm comes from being earnest, repetitive, festive, and a little over-the-top.

## When to Use
Use for requests like:
- 抖音评论区老人爱发的祝福语
- 微信家族群复制粘贴祝福
- 朋友圈长辈风点赞评论
- 早上好、平安健康、发财好运、美女真漂亮、大哥真帅
- "越土越好""带 emoji""整点好玩的"

Do not use for formal greeting cards, business copy, serious condolence messages, or anything that should sound young/cool/minimalist.

## Style Recipe
Mix these ingredients:

| Ingredient | How to use |
|---|---|
| Opening | 早上好、祝福送到、为你点赞、真棒、花开富贵 |
| Blessings | 身体健康、平安幸福、万事如意、好运连连、财源广进、笑口常开 |
| Emotion | 一份问候、一份牵挂、真心祝福、好人一生平安 |
| Emoji | 🌹🌺🙏☀️🌞☕💖👍🍀💰🎉🔥🏠 |
| Rhythm | Short phrases, repeated wishes, symmetrical lines |
| Flavor | Sincere + festive + slightly excessive |
| **Hard Rule** | Every emoji must appear 3+ times per comment. No single emoji. |

## Output Defaults
Unless the user asks otherwise:
- Reply in Chinese.
- Give 20 items if they ask for "一些/来点/生成一些".
- Make each item directly copy-pasteable.
- Use plenty of emoji, but keep it readable.
- **Every emoji repeats 3+ times. Never use a single emoji alone.**
- Include multiple intensity levels if the request says "好玩/整点/越土越好".

## Intensity Levels

### 轻度长辈味
Natural comments with emoji, usable without looking too absurd.

### 标准长辈味
Classic 抖音/微信群祝福 style: 🌹🙏☀️🍀 appear often.

### 爆改复制粘贴风
More line breaks, repeated flowers, grand blessings, slightly funny and exaggerated.

## Make It Funny Without Being Mean
Lean into affectionate parody, not mockery. The tone should feel like "家族群可爱长辈", not insulting elderly people.

Good funny signals:
- Too many flowers in a harmless way
- Grand blessings for tiny situations
- Very earnest praise
- Repeated "平安健康好运来"

Avoid:
- Ageist insults
- Political propaganda
- Scams, miracle cures, superstition that could mislead
- Targeting a real person with harassment or humiliation

## Final Check
Before answering, make sure the output:
- Sounds like a Chinese elder might actually forward it.
- Has enough emoji to match the request.
- **Every emoji appears 3+ times. Single emojis are forbidden.**
- Is directly usable as comments/messages.
- Includes variety instead of repeating one sentence with tiny changes.
