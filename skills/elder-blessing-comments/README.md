|:---|:---|

| **状态** | `stable` |

**一句话:**生成抖音/微信群/朋友圈的长辈风祝福评论,emoji 拉满,直接复制粘贴。

---

## 快速开始

```bash
# 1. 激活
ln -s $(pwd)/skills/elder-blessing-comments ~/.claude/skills/elder-blessing-comments

# 2. 触发
"来点长辈风祝福语,早上的"
"帮我写几条抖音评论,越土越好"
```

## 依赖

无。纯 prompt skill。
